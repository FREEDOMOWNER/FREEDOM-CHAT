MISSION

FREEDOM CHAT was founded in 2026 by GREEN with a singular vision: to provide a secure, private, and uncensored communication platform for users worldwide. In an era of increasing surveillance and data exploitation, we believe that private communication is not a luxury—it is a fundamental human right.

Our platform is built on the principles of privacy by design, anonymous access, and end-to-end encryption. We collect no personal data, require no email addresses, and maintain no logs. Your conversations are yours alone.

SECURITY FEATURES
End-to-End Encryption All communications are encrypted via the Tor network. Your data cannot be intercepted or monitored.
Bcrypt Hashing Passwords, PINs, and recovery phrases are securely hashed with bcrypt - never stored in plain text.
Account Lockout 2 failed login or PIN attempts = 30-minute lockout. Protects against brute force attacks.
Rate Limiting All API endpoints are rate-limited to prevent abuse and DoS attacks.
CSRF Protection All state-changing operations require unique, one-time CSRF tokens.
XSS Prevention All user content is sanitized and escaped - no scripts can execute in your browser.
Tor Native Fully compatible with Tor Browser. The .onion address provides authentication and encryption.
24-Hour Expiry All messages are automatically deleted 24 hours after posting. Nothing is stored forever.

PRIVACY FEATURES
No Email Required Register with just a username and password - no personal information needed.
16-Word Recovery Phrase Your account is secured by a recovery phrase — no email resets, no backdoors.

No Logs We maintain no logs of IP addresses, access times, or user activity.

ROLE SYSTEM

FREEDOM CHAT employs a hierarchical role system that determines user permissions and message limits. Roles are assigned based on user contributions and staff discretion.

Role Color Character Limit Cooldown Links Moderation
USER White 100 chars 5 seconds ❌ ❌
VIP ⭐ Gold 150 chars NO COOLDOWN ✅ ❌
MODERATOR 🛡️ Blue 200 chars NO COOLDOWN ✅ ✅
ADMIN 👑 Purple 250 chars NO COOLDOWN ✅ ✅
OWNER ⚡ Black 300 chars NO COOLDOWN ✅ ✅

⚠️ Message Cooldown: Only the USER role has a 5-second cooldown between messages. All elevated roles (VIP, MODERATOR, ADMIN, OWNER) can send messages without any waiting period.

ANTI-ABUSE SYSTEMS
Auto-Ban 3 link attempts = automatic permanent ban. 3 warnings = automatic ban.
Message Cooldown Regular users: 5 messages per 5 seconds. Prevents spam flooding.
Active Moderation Dedicated moderators can warn, mute, and ban users who violate rules.
Warning System Users receive warnings for rule violations. 3 warnings = auto-ban.
Mute Function Moderators can mute users for 1 hour, preventing them from posting.
Rate Limiting All API endpoints are rate-limited to prevent brute force and abuse.
